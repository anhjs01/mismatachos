# Un rincón para Aleja

Calendario interactivo de **77 días**, del viernes 16 de octubre al jueves 31 de diciembre de 2026. Conserva la estructura visual, el calendario por pasos y el reproductor de YouTube de [protectovl](https://github.com/anhjs01/protectovl), con contenido propio para Aleja.

## Archivos principales
- `index.html`: portada y carta inicial.
- `calendario.html`: calendario de 77 días.
- `contenido-calendario.js`: mensajes, fechas y canción asignada a cada día.
- `catalogo-canciones.js`: catálogo musical con IDs de YouTube.
- `reproductor.js`: reproductor de YouTube y selección de canción por día.
- `style.css`: diseño adaptable.

La reproducción puede requerir una interacción de la usuaria con la página por las restricciones habituales de los navegadores. Se utiliza el reproductor oficial de YouTube.
